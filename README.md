## 🚀 Sobre o Projeto

Bem-vindo ao repositório do **PodFreitas**! Este é o projeto onde daremos vida ao site do nosso podcast.

Este projeto tem dois objetivos principais:

1.  Criar uma casa incrível na web para o PodFreitas.

2.  Servir como nosso campo de treinamento para dominar **HTML, CSS, Git e GitHub** trabalhando em equipe.

## 👥 Nosso Time
